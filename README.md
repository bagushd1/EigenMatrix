# 3D Constellation Matrix Visualizer

Standalone 3D geometric network visualizer powered by Three.js & React Three Fiber (no text labels, clean geometric nodes).

## How to run locally
```bash
bun install
bun dev
```

## How to deploy to Vercel
1. Initialize as a git repo or move to its own repo:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```
2. Push to your GitHub repository.
3. Import to [Vercel](https://vercel.com) & deploy (zero configuration needed).
